# 🍫 Chocolate Sales Analysis (SQL Project)

## 📌 Overview
This project analyzes chocolate sales data using SQL.  
It includes data cleaning, data modeling, and business insights.

## 🛠 Tools
- SQL Server
- SQL (JOIN, GROUP BY, CASE, VIEW)

## 🧱 Database Structure
- customer
- products
- sales
- stores

## 🔧 Data Cleaning
- Fixed inconsistent Product_id, Customer_id, Store_id
- Applied CASE WHEN for mapping
- Ensured data integrity using FOREIGN KEY

## 📊 Key Analysis
- Total revenue by product
- Sales by customer gender
- Store performance

## 💡 Insights
- Top-selling products identified
- Revenue trends analyzed
- Customer behavior explored
